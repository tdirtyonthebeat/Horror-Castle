# Horror Castle v1.1 visual reference

`HorrorCastle_v1.1_UI_Reference.png` is the generated art-direction target for the v1.1 skin.
The runtime UI does not simply paste this screenshot behind controls. Instead, it reconstructs the visual vocabulary in JUCE so controls remain interactive, scalable, readable, and maintainable.

The supplied castle artwork is embedded as the live header image; stone frames, arches, runes, sigils, control bezels, torches, and fog are drawn procedurally.
