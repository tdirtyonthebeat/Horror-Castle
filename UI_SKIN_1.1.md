# Horror Castle v1.1 — The Castle Awakens

This branch changes the visual shell and factory Grimoire while keeping the v1.0 DSP implementation untouched.

## New visual architecture

- procedural black-stone panels and rune borders
- CRYPT crimson / TOWER violet accent identities
- gothic arch framing and hooded-niche motifs
- castle skyline header using the supplied Horror Castle artwork as an embedded asset
- forged-metal rotary/linear controls and styled dropdowns/buttons
- subtle timer-driven mist and torch ambience
- restyled HEX ritual geometry and Curse Inspector stone frame
- dedicated full-screen Grimoire overlay

## Expanded Grimoire

32 factory spells across CRYPT, TOWER, POSSESSION, HEXED, RITUALS and ATMOSPHERE categories. The browser supports category filtering, search, local favorites, factory summoning, and user .hcg save/load.

## DSP freeze

CastleEngine, RitualEngine, GraveChamber, PossessionEngine, RitualsEngine, CurseMatrix and CurseChain are carried forward unchanged from the v1.0 release package.
